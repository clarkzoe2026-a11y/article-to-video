# 视觉风格

深色底 + 黑白灰 + 唯一亮色，编辑感排版（漫行书海视觉风格，参考而非冻结规范）。

## 配色（engine/src/Video.jsx 的 C 对象）

| Token | 值 | 用途 |
|---|---|---|
| bg | `#0D0D0D` | 背景（深色，用户要求，避免框选时中间出现突兀暗块） |
| panel | `#1A1A1A` | 面板、标题栏 |
| line | `#3A3A3A` | 边框、未到达的步骤 |
| sub / muted | `#8E8E8E` / `#5A5A5A` | 次要文字 |
| ink | `#F2F2F0` | 主文字 |
| **accent** | **`#DDFB78`** | **唯一亮色**：高亮框、聚光、当前步骤、主讲提示、打勾。亮色块上的文字用深色 |

不要引入其他亮色（终端红黄绿圆点也改成灰色）。文章自带的插画/截图保留原色。

## 字体

标题、片尾标题：宋体（Songti SC）做编辑感；正文、字幕：苹方（PingFang SC）；代码：Menlo。

## 字幕（用户确认）

- 48px 白字，深色半透明底，**无描边、无「主讲/提问」标签**。
- 每屏 ≤18 字，按标点断句，停顿处用空格，去掉逗号句号，保留问号感叹号。
- 念法自动换回写法（四七点九八 → 47.98，二百 OK → 200 OK……）。

## 动画节奏

- 换图：新图在上层匀速淡入，旧图保持到被盖住再淡出（不透出黑底）。
- 截图推近：先全图 ~1.1 秒并框出位置，再 0.7 秒推近；光标 0.5 秒移入后点击。
- 同图连续高亮：遮罩保持，高亮框 0.7 秒滑动；首次压暗 0.8 秒。
- 开场弹出：0.96→1 缩放 + 淡入 0.4 秒（不抖动）。
- 画面区 1760×740，顶栏标题 + 右上角步骤条，底部字幕。
