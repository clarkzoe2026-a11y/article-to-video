# 宣传片设计语言（与讲解视频分开）

讲解视频的规则（`STYLE.md`、`SHOTS_GUIDE.md`）是为了「看清每一步」；宣传片的目标是「60 秒内让人想用」，规则不同。
实现：`engine/src/promo/Promo.jsx`（合成 id「Promo」），数据由文章目录下的 `build_promo.py` 打包。

## 1. 两件「物」贯穿全片

| 物件 | 代表 | 外观 |
|---|---|---|
| **手机** | 文章（读者在公众号里读） | 白底屏幕、状态栏 9:41、公众号顶栏；文章按公众号排版真实还原 |
| **显示器** | 视频（观众在视频平台看） | 深色边框 + 底座；屏幕里是真实成片，底部有播放进度条和成片时间码 |

- 只要画面里同时出现文章和视频，就一定是「左手机、右显示器」，观众不用读标签也知道哪边是什么。
- 两边**讲同一处内容**：手机滚到哪张图，显示器就在播哪张图；元素从手机「飞」进显示器，表示「文章变成视频」。

## 2. 文案

- **说结果，不说功能**；不限定文章类型（不写死「实操教程」）。
- 每屏只放一个信息；大字一行 ≤ 10 字。
- 数字要真实，来自第一支成片（28 个镜头、206 处同步、1 次配音、13:58 时长）。
- 不出现其他产品的名称和商标（例如剪辑软件用通用的「多轨时间线」图形表示）。

## 3. 版式

- 字号阶梯（1080p）：展示 110–150 / 标题 60–72 / 小标题 36–40 / 正文 26–30 / 最小 20。
- **背景禁止纯黑**（用户 2026-10-08）：用有空间感的深色舞台——顶部柔光 + 远处透视地面网格 + 缓慢漂移的环境光 + 暗角（`Backdrop`），**不画地平线横线**。这套背景与作者的知识视频系列共用（用户 2026-10-08 确认），色值：顶部 `#1E2428` → 中部 `#14181C` → 四周 `#0C0F12`；改动要两边同步。转折处「关灯」也只是把舞台压暗，不切纯黑。
- 颜色：底 `#101316`（深石板色），面板 `#161616`，线 `#2E2E2E`，字 `#F4F4F2`，次要 `#8E8E8E`；**唯一亮色 `#DDFB78` 只给「变化和结果」**（飞出、确认、计数结果、当前步骤）。
- 安全区：四边 ≥ 80px；底部 940px 以下留给字幕，其他元素不进入。
- 不叠字：标签、气泡、终端一律放在画面框外，不压在成片画面上。

## 4. 运动

- 进场：out-expo 曲线 0.5 秒；出场 0.3 秒；「飞」：in-out 曲线 0.6 秒。
- 段落切换和卡片进场落在音乐重拍上（120 BPM，半秒一拍）。
- 同一时刻最多两个东西在动，观众的视线只跟一个主角。
- 每个动效都要表达一个意思（飞 = 转化，盖章 = 你确认，计数 = 规模），不为炫技。

## 5. 画面不留空

- 旁白在说话时画面必须有对应的内容，不允许出现只有背景的空档（2026-10-08 用户指出 4–6 秒空白）。

## 6. 声音

- 前段音乐安静 → 转折处骤停、只剩敲键盘声 → 回车时从曲子高潮段接入。
- 旁白时音乐压低到约 40%；插入成片原声时压到约 12%。
- 音效只给有意义的事件：转场（whoosh）、回车（click）、确认盖章（select）、落拍（impact）。
- **插入成片原声必须是完整的句子**：起止点落在句与句之间的停顿里（按波形音量找静音），不能停在半句话；剪完用 faster-whisper 转写整片复核（剪点由波形定，不按转写时间机械切）。
