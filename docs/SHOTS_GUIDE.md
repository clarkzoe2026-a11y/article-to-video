# 画面安排指南（shots.py）

画面跟着口播走：**说到哪个词，画面就切到哪里**（语义同步）。每篇文章在自己的 `shots.py` 里描述，工具函数在 `pipeline/shotlib.py`。

## 1. 触发：at(line, kw)

- `at(3, "添加记录")`：说到第 3 句（从 0 数）里的「添加记录」时切换。
- `at(3)`：第 3 句开头切换。每个镜头的第一个画面会自动从镜头开头就显示（避免空屏）。
- **关键词要放在短句的开头**：「让搬运工去 GitHub 把代码拉回来」用「让搬运工」，不用「拉回来」，否则画面会晚一拍。
- 关键词必须真的出现在台词里，`./a2v shots` 会逐个校验，对不上就报错。

## 2. 四种画面

| 写法 | 效果 | 用在 |
|---|---|---|
| `full(a, "008")` | 整张图 | 插画、总图、上下文 |
| `zoom(a, "029", rect)` | 换图时**先展示全图并框出位置**，约 1 秒后推近 | 截图里的具体按钮/输入框 |
| `zoom(..., click=True)` | 推近后光标移过去点击 | 需要「点」的按钮 |
| `spot(a, "008", rect)` | 全图压暗、只亮一块 | 总图/插画里依次讲各格 |

- 同一张图连续 `spot`：**遮罩不动，高亮框滑过去**（用户反馈过一亮一暗刺眼）。
- 同一张图连续 `zoom`：镜头平移到下一个位置。
- `pop=True`：开场第一张图平滑弹出（不要抖动，用户反馈过卡顿）。

## 3. 面板（盖在画面区上，顶栏和字幕保留）

```python
code(at(2), "宝塔终端", [
    cmd("git clone https://github.com/...", "搬运工去 GitHub 拉货", at(2, "让搬运工"), mark=at(4, "git clone")),
], result={"lines": ["HTTP/1.1 200 OK"], "ok": "通路了", "at": at(1, "二百")})
status(at(2), [{"code": "404", "text": "地址找错了", "at": at(3, "四零四")}, ...])
browser(at(2, "浏览器"), "bookdot.cn")
card(at(0))   # 片尾卡片（meta.json 的 outro：kicker 小标题、title、subtitle、link、cover 封面图号、account 公众号）
clip(at(1, "关键词"), "video/demo.mp4", 274.6, label="截图自动推近")   # 剪入一段视频（静音，默认裁掉其底部字幕区）
stats(at(0), [{"value": 14, "unit": "分钟", "label": "成片", "at": at(0)}])  # 大数字卡片
flow(at(0), [{"name": "抓取", "at": at(1, "抓取"), "gate": True}])           # 流程图，gate 显示「你来确认」
scroll(at(0), ["001", "006", "008"])                                         # 几张图竖排匀速上滚（长文的感觉）
```

## 4. 框选坐标 rect = [x, y, w, h]（0~1 比例）

- **截图**：作者通常已用红框标出要点。`./a2v redboxes` 自动识别，`./a2v contact <目录> out/c1.jpg 021,023` 生成带序号的缩略图墙，然后在 shots.py 里写 `rb("023", 2)`。
- **插画**：橙色会被误识别成红框，不要用 rb；手写比例坐标，横排多格用 `cols(n, x0, x1, y0, y1)` 均分。
- 不确定时宁可框大一点；最大放大倍数 2.4 倍，以保留上下文。
