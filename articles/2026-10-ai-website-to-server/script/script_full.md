# AI 建网站不再被平台拿捏：零基础搬上服务器（完整版）

## 1. 开场：网站成了平台的人质
*画面：402 报错页弹出抖动；停服公告推近高亮“连续 90 天无访问”；封面图*

**🅱️ 新手**：我前阵子用 Coze 半小时就搓出来一个网站，特别酷。结果前两天打开一看，直接给我弹了个 402。
**🅰️ 主讲**：哈，是不是写着：此应用已停止服务，充值积分后才能访问？
**🅱️ 新手**：对对对！你怎么知道？
**🅰️ 主讲**：因为网站是放在平台上的嘛。积分一没，或者规则一调整，比如连续九十天没人访问就给你停了，你一点办法都没有。说白了，网站成了平台的人质。
**🅱️ 新手**：那怎么办，就这么认了？
**🅰️ 主讲**：当然不。今天就干一件事：把网站搬进你自己的服务器。从此二十四小时，自己说了算。

## 2. 这些情况，值得搬
*画面：适合人群图(006)六格依次点亮*

**🅱️ 新手**：那是不是所有网站都得搬？
**🅰️ 主讲**：也不是。如果你受够了平台的规则，或者网站得一直在线，不能说停就停，那就值得搬。
**🅰️ 主讲**：还有一种，网站里有登录、有 AI 对话、要上传下载文件，甚至涉及支付，这些都需要一个随时在岗的后台，放在自己服务器上更踏实。
**🅱️ 新手**：前提是愿意花点钱买服务器和域名，对吧？
**🅰️ 主讲**：对，这是唯一的门槛。

## 3. 前置准备与成本
*画面：成本插画(007)五列依次聚光*

**🅱️ 新手**：可是自己买服务器，听着就很贵，也很难。
**🅰️ 主讲**：其实没你想的那么夸张。网站本身，很多 AI 平台都能免费做；GitHub 账号也免费。真正花钱的就两样：域名一年五六十块，服务器新手第一年大概六十到一百，之后续费会贵一些，一年几百。
**🅱️ 新手**：哦，一年也就一两百块的事。
**🅰️ 主讲**：而且网站在哪个平台做的都没关系，只要最后能拿到完整代码，后面这套搬家路线都一样。

## 4. 一图看懂 10 步全流程
*画面：全流程图(008)：讲到哪格亮哪格（高亮框滑动）*

**🅰️ 主讲**：整个过程，你可以想象成：给你的网站在云上安个家。
**🅱️ 新手**：安家？
**🅰️ 主讲**：对。第一步，先把家当打包，放进云仓库，也就是上传到 GitHub。然后租一套永远不关机的云上房子，就是服务器。
**🅰️ 主讲**：房子有了，得挂个门牌，这是设置 DNS；再把房门打开，就是开放端口；然后给房子通水通电，装好运行环境。
**🅱️ 新手**：听着还真像装修。
**🅰️ 主讲**：没错。接下来把仓库里的家当搬进房子，请个管家二十四小时守着，在门口挂个引路牌，再给大门装把防盗锁。最后，网站有更新的话，就重新搬一次新家当。
**🅱️ 新手**：十步，好像也没那么吓人了。
**🅰️ 主讲**：好，我们一步一步来。先打包家当。

## 5. 第 1 步：搬家前先验货
*画面：第1步两格插画(009)→ 平台界面截图(010→011)：先看全图再推近“运行正常”*

**🅱️ 新手**：打包之前，要先做什么吗？
**🅰️ 主讲**：先在平台上把网站点一遍，确认能正常打开、能正常用。
**🅱️ 新手**：为什么要多这一步？
**🅰️ 主讲**：这样搬完以后如果打不开，你就知道是搬家搬坏了，不是网站原来就有毛病，排查起来省事多了。

## 6. 第 1 步：把家当放进云仓库
*画面：装箱插画(012)→ Coze 版本控制截图(013→014→015)，推近“去连接”“有未推送的更改”“Push”并点击*

**🅰️ 主讲**：接下来打包。以 Coze 为例，找到「版本控制」，第一次用的话点「去连接」，这一步就是打开 GitHub 的大门。
**🅱️ 新手**：我还没有 GitHub 账号呢。
**🅰️ 主讲**：没关系，点了「去连接」会跳到注册页面，免费注册一个，登录就行。
**🅰️ 主讲**：连上以后，「版本控制」右边会显示：有未推送的更改，几个。意思是这几样家当还没放进云仓库。点「Push」，在确认弹窗里再点一次「Push」。
**🅱️ 新手**：就这样，家当就进仓库了？
**🅰️ 主讲**：对，云仓库里还会留着每一次的历史记录，以后想找回旧版本也方便。

## 7. 第 2 步：租一套云上房子
*画面：阿里云购买页截图(016)：依次推近“宝塔 Linux 面板”、地域、配置、“自动续费”；再到已购服务器(017)*

**🅱️ 新手**：家当有地方放了，房子去哪租？
**🅰️ 主讲**：我用的是阿里云的轻量应用服务器。个人展示网站，或者访问量不大的，选基础配置就够了。
**🅰️ 主讲**：系统镜像这里选「宝塔 Linux 面板」，后面装环境、管网站都靠它。地域选离你近的。
**🅱️ 新手**：有什么要特别注意的吗？
**🅰️ 主讲**：有一个：如果你不打算续费，记得把「自动续费」的勾去掉。

## 8. 第 3 步：DNS 是什么
*画面：DNS 插画(018)分区推近：IP vs 域名 → 对暗号三格 → 小本本*

**🅰️ 主讲**：服务器买好之后，其实它就已经有地址了。
**🅱️ 新手**：地址？哦，就是那个 IP 对吧，四七点九八点几点几那种？
**🅰️ 主讲**：对，就是那一串数字。但你说，这玩意儿谁记得住啊？
**🅱️ 新手**：哈，确实记不住。所以才要买域名嘛，像 bookdot 点 cn 这种。
**🅰️ 主讲**：没错。可问题是，访客输进去的是域名，浏览器怎么知道该去找哪台服务器呢？
**🅰️ 主讲**：这就轮到 DNS 出场了。你就把它想象成一个对暗号的小本本。访客说，我要去 bookdot 点 cn，DNS 翻一下本子：哦，那是四七点九八那套房子，往这边走。
**🅱️ 新手**：懂了，所以设置 DNS，其实就是把这对暗号写进小本本里？
**🅰️ 主讲**：就是这个意思。

## 9. 第 3 步：DNS 实操三步
*画面：同 P0 s5_dns_steps（019、021、023、024、028、029、030、031、032）*

**🅰️ 主讲**：操作上就三步，还是用房子来记。第一步，进物业大厅。在阿里云工作台里搜「云解析 DNS」，点进去。
**🅰️ 主讲**：第二步，跟前台说我要登记门牌。点「公网权威解析」，再点「添加域名」，把你已经备案好的域名填进去。
**🅱️ 新手**：没备案的不行吗？
**🅰️ 主讲**：不行，没备案它不认。好，第三步，填门牌登记表。在域名后面点「解析设置」，再点「添加记录」。
**🅰️ 主讲**：记录类型选 A，主机记录填一个艾特符号，代表前面什么都不带的域名。记录值，就填你服务器的公网 IP。
**🅱️ 新手**：公网 IP 去哪儿找？
**🅰️ 主讲**：在服务器详情里，标着「公」字的那个，复制过来就行。然后点「添加并继续」，再加一条，主机记录填 www，记录值还是同一个 IP。
**🅱️ 新手**：这样带不带 www 都能找到了。
**🅰️ 主讲**：对，两条记录就齐了。

## 10. 第 3 步：验证门牌
*画面：终端动画：nslookup bookdot.cn → 返回 IP*

**🅱️ 新手**：填完马上就能用吗？
**🅰️ 主讲**：别急，生效可能要几分钟，也可能要几个小时。你可以在终端里敲一下 nslookup 加上你的域名，只要返回的是你服务器的 IP——
**🅱️ 新手**：那就说明门牌已经认路了！

## 11. 第 4 步：端口就是房门
*画面：开放端口插画(033)→ 端口房间图(038)：80/443、22 依次聚光*

**🅱️ 新手**：门牌挂好了，访客是不是就能进来了？
**🅰️ 主讲**：还不行，门还关着呢。服务器就像一套房子，里面有好几扇门，每扇门有个编号，这就是端口。
**🅰️ 主讲**：比如 80 和 443，是给访客看网站走的大门；22 是后门，专门给你远程管理服务器用的。
**🅱️ 新手**：那 80 和 443 有什么区别？
**🅰️ 主讲**：80 是普通大门，数据在路上是明文的，别人截到就能看清；443 是带锁的门，数据会加密，别人截到也看不懂。

## 12. 第 4 步：开门三步
*画面：三步插画(034)→ 工作台(035)→ 服务器列表(036)→ 防火墙(037)：推近“防火墙”与端口列表*

**🅰️ 主讲**：开门也是三步。先找到房子：在阿里云工作台点「轻量应用服务器」，再点「查看详情」。
**🅰️ 主讲**：然后找到门口的保安，也就是「防火墙」。你会看到，有些端口默认已经开了。
**🅰️ 主讲**：80 和 443 的来源是一串零，意思是不限地址，谁都可以来敲门。网站本来就是给所有人看的，这样没问题。

## 13. 第 4 步：后门只给自己开
*画面：22 端口规则(040)→ 搜“我的公网 IP”(041)→ 添加规则(042→043)→ 规则列表(044)：推近“来源 IP”“8888”*

**🅱️ 新手**：那 22 号后门呢？
**🅰️ 主讲**：后门绝不迎客。点这条规则右边的「修改」，来源 IP 只填你自己电脑的 IP。
**🅱️ 新手**：我电脑的 IP 怎么查？
**🅰️ 主讲**：在浏览器里搜「我的公网 IP」，把显示的 IPv4 地址复制过去。
**🅰️ 主讲**：接着再开一扇房主专用门：点「添加规则」，协议选 TCP，端口填 8888，来源同样只填你电脑的 IP。这是宝塔面板的门，等会儿就要用。
**🅱️ 新手**：要是我换了网络呢？比如从公司回到家。
**🅰️ 主讲**：那你的 IP 会变，得回来把新 IP 加上，不然会把自己挡在门外。记住一句话：80、443 对所有人开，22 和 8888 只对自己开。

## 14. 第 5 步：推开房主专用门
*画面：插画(045→046)→ 应用详情(047)→ 执行命令拿账号密码(048)→ 登录页(049)→ 宝塔首页(050)*

**🅱️ 新手**：门开好了，接下来是通水电？
**🅰️ 主讲**：对。不过要先进屋，从刚才那扇房主专用门进去。在服务器详情里，从「防火墙」切到「应用详情」，点「打开网站页面」，这就是 8888 号门。
**🅱️ 新手**：进门要密码吧？
**🅰️ 主讲**：要。在应用详情里点「执行命令」，就能拿到账号和密码，复制过去登录。看到提示激活或绑定的，先跳过，不影响这次部署。

## 15. 第 5 步：接通水电
*画面：通水电插画(051)→ 网站页“安装 Nginx”(052)→ 软件商店(053)*

**🅰️ 主讲**：进屋你会发现，房子还没通水电。网站想跑起来，得先把这套基础设施铺好，这就是运行环境。
**🅰️ 主讲**：点左边的「网站」，第一次进去会提醒你还没安装运行环境，直接点「安装 Nginx」。
**🅱️ 新手**：要是没弹这个提示呢？
**🅰️ 主讲**：也可以去「软件商店」，在官方应用的运行环境里挑一个免费的，安装方式选「极速安装」，版本用默认的稳定版就行。

## 16. 第 6 步：拿到提货单
*画面：三步插画(054)→ 提货单(055)→ GitHub Code 截图(056)：推近 HTTPS 地址*

**🅱️ 新手**：门牌挂了，门开了，水电也通了，可家当还在云仓库里呢。
**🅰️ 主讲**：对，现在就把家当搬进来。
**🅰️ 主讲**：搬家先要拿提货单。打开你的 GitHub 仓库，点绿色的「Code」，复制里面的 HTTPS 地址。
**🅱️ 新手**：这就是仓库的地址？
**🅰️ 主讲**：对，等会儿让搬运工照着这个地址去拉货。

## 17. 第 6 步：喊搬运工干活
*画面：搬运工插画(057)→ 代码动画逐行出现（mkdir/cd、git clone、corepack、pnpm install、pnpm run build），每行旁边标比喻 → 宝塔终端截图(058)*

**🅱️ 新手**：搬运工是谁？
**🅰️ 主讲**：就是 Git，一个专门把代码从云端搬进服务器的工具。打开宝塔左边的「终端」，把几行命令贴进去就行。
**🅰️ 主讲**：这几行命令分别是：进到放网站的房间，让搬运工去 GitHub 把代码拉回来，然后叫装修队把需要的零件装好，最后按图纸精装修，也就是打包构建。
**🅱️ 新手**：命令我照抄就行？
**🅰️ 主讲**：有一处要改：git clone 后面的地址，换成你刚才复制的那个。还有，带井号的那几行是说明，复制的时候去掉。

## 18. 第 6 步：看到完工
*画面：构建结果截图(059)：推近 Build completed successfully!*

**🅱️ 新手**：怎么知道搬完了？
**🅰️ 主讲**：看最后一行，如果是 Build completed successfully，就是装修队长在汇报：家具搬完，精装修搞定。
**🅱️ 新手**：要是满屏红字呢？
**🅰️ 主讲**：别慌。把报错截图，连同你的 GitHub 仓库地址一起发给 AI，问它怎么办，再把它给的命令贴回终端就行。

## 19. 第 7 步：请管家 24 小时守着
*画面：管家插画(060)→ 代码动画（pm2 start / pm2 save / curl）→ 启动结果截图(061)：推近 online 与 200 OK*

**🅱️ 新手**：装修好了，网站就能访问了吗？
**🅰️ 主讲**：还差一个管家。网站得一直有人看着，挂了要能自己爬起来，这个管家就是 PM2。
**🅰️ 主讲**：在终端里，让管家在五千号房间上岗，给它起个名字；再让它记住这张班表，服务器重启也不怕；最后喊一声，看它在不在。
**🅱️ 新手**：怎么算喊应了？
**🅰️ 主讲**：看到 online，说明管家已经上岗；看到二百 OK，说明网站在屋里跑得很顺。没看到的话，还是老办法，把红字发给 AI。

## 20. 第 8 步：立个接待台
*画面：引路牌三步插画(062)→ 接待台(063)→ 添加站点(064→065)→ 站点列表(066)*

**🅱️ 新手**：管家在五千号房间，访客能直接找到它吗？
**🅰️ 主讲**：找不到。访客只认 bookdot 点 cn 这块门牌，根本不知道屋里还有个五千号房。所以要先在门口立个接待台。
**🅰️ 主讲**：在宝塔里点「网站」，再点「添加站点」，把你的域名填进去，一行一个，其他保持默认，点「提交」。

## 21. 第 8 步：挂上引路牌
*画面：指路插画(067)→ 设置(068)→ 反向代理(069)→ 添加反向代理(070)：推近目标 URL 与发送域名 → 列表(071)*

**🅱️ 新手**：接待台有了，怎么把人领到五千号房？
**🅰️ 主讲**：靠门口的指路大爷，也就是反向代理。访客说找 bookdot 点 cn，大爷抬手一指：往里走，五千号房。
**🅰️ 主讲**：在站点右边点「设置」，找到「反向代理」，点「添加反向代理」。打开代理，起个名字，目标地址照屏幕上这一串填：一二七点零点零点一，冒号五千；发送域名填 host，点「确定」。
**🅱️ 新手**：一二七点零点零点一是什么？
**🅰️ 主讲**：就是这台服务器自己。冒号后面的五千，就是管家待的那间房，一定要和刚才启动时填的一样。

## 22. 第 8 步：测一测通没通
*画面：测试插画(072)→ 终端动画 curl -I http://bookdot.cn → 200 OK 截图(073)；状态码小卡片 200/404/502/500*

**🅱️ 新手**：怎么知道通了没？
**🅰️ 主讲**：在终端里用 curl 访问一下你的域名，看到二百 OK，就是通了：访客从大门进来，大爷一指，顺利见到管家。
**🅱️ 新手**：要是看到别的数字呢？
**🅰️ 主讲**：四零四，是地址找错了；五零二，多半是端口没开，或者管家挂了；五零零，是网站代码自己报错了。

## 23. 第 9 步：领一把免费的锁
*画面：防盗锁三步插画(074)→ 锁(075)→ SSL 设置(076)→ 申请证书(077)：推近“文件验证”→ 证书列表(078)*

**🅱️ 新手**：网站终于能打开了！
**🅰️ 主讲**：能打开了，但大门还没上锁。现在走的是 80 那扇普通大门，数据在路上没加密，我们把它换成带锁的门。
**🅱️ 新手**：锁去哪里领？要花钱吗？
**🅰️ 主讲**：免费的。这把锁叫 SSL 证书。在宝塔的站点右边点「设置」，找到「SSL」，选「Let's Encrypt」，点「申请证书」。
**🅰️ 主讲**：验证方式选「文件验证」，域名全选，点「申请证书」。
**🅱️ 新手**：有什么前提吗？
**🅰️ 主讲**：有两个：门牌得挂稳，也就是 DNS 已经生效；80 号门得开着。不然发证的机构找不到你家，就不给你发锁。

## 24. 第 9 步：所有人都走防盗门
*画面：两扇门插画(079)→ 强制 HTTPS 截图(080)：推近开关；浏览器地址栏小锁动画*

**🅱️ 新手**：锁领到了，就安全了吗？
**🅰️ 主讲**：还要再做一步：强制 HTTPS。意思是，就算访客非要走没锁的 80 门，也把他领到 443 的防盗门去。
**🅰️ 主讲**：切到「当前证书」，打开「强制 HTTPS」。然后在浏览器里打开你的网站，地址栏变成 https，还带个小锁，就说明锁装好了。
**🅱️ 新手**：这把锁能用多久？
**🅰️ 主讲**：九十天。不过只要 80 和 443 两扇门开着，宝塔一般会自动续期，不用你每三个月换一次。

## 25. 第 9 步：到期提前提醒
*画面：提醒插画(081)→ 到期提醒设置(082→083)→ 飞书建群、群设置、群机器人、自定义机器人(084→089)→ 提醒效果(090)→ 选择飞书(091)*

**🅱️ 新手**：万一续期失败了呢？
**🅰️ 主讲**：那就加个保险：快到期时让飞书提醒你。在宝塔的证书页点「到期提醒设置」，设好提前几天提醒，通知方式选飞书。
**🅱️ 新手**：飞书那边要怎么弄？
**🅰️ 主讲**：在飞书里建一个群，进群设置，找到「群机器人」，添加一个「自定义机器人」。名字和描述用默认的就行，点「添加」。
**🅰️ 主讲**：再回到宝塔的到期提醒配置，通知方式选上这个飞书机器人。到时候，群里就会收到提醒。

## 26. 第 10 步：以后怎么更新
*画面：后续更新插画(092)六步依次点亮 → 代码动画（git pull / pnpm install / pnpm run build / pm2 restart）*

**🅱️ 新手**：以后我在 AI 编程工具里改了网站，又得重新搬一遍吗？
**🅰️ 主讲**：不用从头来，只要四句话。先把新改动推到 GitHub，然后在宝塔终端里：让搬运工把新家当拉回来，让装修队补齐新零件，按新图纸重新装修，最后请新管家接班。
**🅱️ 新手**：就这样？
**🅰️ 主讲**：就这样。刷新一下浏览器，就能看到新页面了。
